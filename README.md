
# 🍅 Pomodoro Timer

A modern and responsive Pomodoro Timer web application built using pure HTML, CSS, and JavaScript.

This project helps users stay productive using the Pomodoro Technique by managing focus and break sessions with an interactive and visually clean interface.

---

## ✨ Features

* ⏱️ Focus and Break Timer
* ▶️ Start Timer
* ⏸️ Pause Timer
* 🔄 Resume Timer
* ♻️ Reset Timer
* 🔔 Alarm Sound on Session Completion
* 🔁 Automatic Focus ↔ Break Switching
* 📜 Daily Session History
* 💾 LocalStorage Support
* 🌙 Dark Mode Toggle
* 📱 Fully Responsive Design
* ⌨️ Keyboard Shortcuts
* 📊 Daily Statistics
* 🎨 Smooth Animations

## 🚀 How to Run

### Method 1 — Directly in Browser

Simply open:

```bash
index.html
```

in any browser.

---

### Method 2 — Using VS Code Live Server (Recommended)

1. Open project folder in VS Code
2. Install "Live Server" extension
3. Right click on `index.html`
4. Click:

```bash
Open with Live Server
```
